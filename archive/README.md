# Archive

Date archived: 2026-09-19.

This folder holds code that was removed from the live, deployed surface at
`apps/web/` but kept (rather than deleted) so the history and the ideas in it
stay recoverable. **Nothing under `archive/` is deployed, built, or checked**
by `scripts/build-web.mjs` / `scripts/check-web-build.mjs`, and it is not
served by the Cloudflare Worker's static-assets binding (see
`apps/worker/wrangler.toml`, `directory = "../web"` — `archive/` is a sibling
of `apps/`, outside that directory, so it is unreachable from the deployed
site).

## web-slop-o-meter/

The "Slop-o-meter" demo page (`demo/Slop-o-meter.html`) and every file under
`apps/web` that only it used. Moved here with `git mv`, so `git log --follow`
on any file inside still finds its full history.

**Why it was archived, not fixed in place:**

1. It is broken. It never mounts its own layers and is permanently stuck on
   an "engine loading" state — it does not work if you open it today.
2. It is the thing `PRODUCT.md` explicitly rules out. `PRODUCT.md` names
   "a parody-first anti-slop museum that makes visitors endure bad interfaces
   before seeing good ones" as an anti-goal, and `DESIGN.md`'s creative north
   star ("The Evidence Workbench") repeats the same line almost verbatim as a
   "don't." The Slop-o-meter's whole conceit — walk the visitor through slop
   examples first — is that museum.
3. The real product superseded it. `apps/web/index.html` (the decision
   bench: Generate / Audit / Humanize) is what `PRODUCT.md` and `DESIGN.md`
   now describe, and it does not use any of these files.

**What's here** (`web-slop-o-meter/demo/`, mirroring the original
`apps/web/demo/` layout so relative paths inside these files still resolve
*to each other*):

- `Slop-o-meter.html` — the page itself. Loads React/ReactDOM in
  **development** mode plus `@babel/standalone` to transpile `.jsx` files
  live in the browser (no build step) — fine for an archived curiosity, not
  something that should ever ship.
- `app-data.js`, `image-slot.js` — data and the `<image-slot>` custom
  element used only by this page.
- `tweaks-panel.jsx`, `chrome.jsx`, `slop-act.jsx`, `second-order-act.jsx`,
  `index-act.jsx` — the museum's chrome and act/scene components.
- `pg-buttons.jsx`, `pg-compose.jsx`, `pg-copy.jsx`, `pg-glass.jsx`,
  `pg-gradient.jsx`, `pg-motion.jsx`, `pg-space.jsx`, `pg-type.jsx` — the
  "page" specimens `Slop-o-meter.html` loads directly by `<script
  type="text/babel">`.
- `pg-color.jsx`, `pg-controls.jsx`, `pg-imagery.jsx`, `pg-text.jsx` — page
  components that `scripts/build-web.mjs` used to compile into
  `apps/web/build/`, but that were not referenced by *any* live page (not
  even `Slop-o-meter.html`'s own script list) — dead weight kept here for
  the same reason as the rest of this folder rather than deleted outright.
  (`pg-text.jsx` defines `PageText`, which `apps/web/index.html` used to
  load via `build/pg-text.js`, but nothing ever rendered it — see
  `apps/web/README.md`.)
- `pg-data.jsx`, `pg-soft.jsx`, `pg-surfaces.jsx` — page components that
  were not referenced anywhere at all: not compiled by
  `scripts/build-web.mjs`, not loaded by `Slop-o-meter.html`'s script list,
  not loaded by any other file. Fully orphaned; archived rather than
  deleted for the same "don't lose history" reason as the rest of this
  folder.

**What was *not* moved**, because the live decision bench in
`apps/web/index.html` still uses it (or another tool owns it): `apps/web/demo/textslop-summary.js` (generated by `textslopbench/export_web_summary.py` and checked by `tests/test_local_benchmarks.py`; no page loads it today), `apps/web/demo/app.jsx` (the real
Generate/Audit/Humanize app — `Slop-o-meter.html` happened to load the same
file, but it is not exclusive to the museum) and `apps/web/demo/app-styles.css`
(shared stylesheet). If you want to run `Slop-o-meter.html` locally, copy (or
symlink) those two files from `apps/web/demo/` into this folder first —
without them it will fail even faster than it already did.

**Generator scripts**, referenced from `apps/web/README.md` for the
`apps/web/viz/*.html` files that remain live (unrelated to the Slop-o-meter,
listed here only because both are "generated, not hand-edited" surfaces):
`viz/personality-test/build-cross-gate.mjs`,
`viz/personality-test/color/build-color-slop-ranked.mjs`,
`viz/personality-test/color/build-color-space-map.mjs`,
`viz/personality-test/color/build-density-map.mjs`, and
`scripts/build-projection.py`.
