# Composition & boldness — a different layout, type move, and bold idea every time

Mandatory read. The anti-slop gates fixed fonts/colors but collapsed *composition*:
every build converged to one timid template. This file is the fix — pick a **different
layout archetype + bold type move + characterful font** each build. **Bold ≠ slop:**
boldness comes from scale, contrast, structure, conviction — never from banned colors,
gradients, or glassmorphism.

**The median to AVOID by name:** *headline-left + widget-card-right split hero* — big
left headline, tidy bordered card on the right with a fake metric/sparkline/"tool",
mono kicker, left-aligned, warm cream ground. If that's your first instinct, it's the
median. Refuse it.

## Layout archetypes (pick ONE as the spine; a DIFFERENT one each build)
1. **Full-bleed type poster** — the headline *is* the page, type edge-to-edge at poster scale.
2. **Broken / asymmetric grid** — a real grid with one element deliberately violating it.
3. **True split-screen** — two full-bleed fields that argue (NOT a headline + card).
4. **Editorial multi-column with rules** — visible disciplined newspaper grid (earn it with real text).
5. **Oversized index / giant numeral** — a real number/list at display scale is the layout.
6. **Diagonal / rotated axis** — tilted headline/marquee or vertical side label; rotate the statement, not the paragraph.
7. **Collage / scrapbook / sticker** — layered overlapping fragments, readable like a document.
8. **Single hero object, massive & centered** — one subject-grounded form on a bare stage.
9. **Horizontal-scroll / marquee** — lateral movement; must degrade vertically; marquee must *say* something.
10. **Brutalist dense info grid** — raw, high-density, structure foregrounded; rigor, not sloppiness.
11. **Zine / maximalist layered** — clashing display faces, texture, owned high-contrast color over a rigorous grid.
12. **Terminal / document / spreadsheet** — borrow a real document form and mean it (real tabular data).

**Coverage rule:** don't repeat an archetype across consecutive builds. Two split-heroes (or two posters) in a row is convergence.

## Typographic range (pick a DIFFERENT primary move; the italic-accent word is RETIRED)
The retired cliché: *one italic-serif accent word* dropped into a grotesque headline. Don't default to it.
1. **Dramatic scale contrast** — massive H1 vs tiny caption; the ratio is the design (empty middle of the scale).
2. **Ultra-bold / black weight** — commit to 800–900 as the voice, not a safe 600.
3. **Condensed / compressed display** — ultra-narrow stacked tall (statement only, not body).
4. **All-caps stacked lockup** — caps, one word per line, `line-height:0.9`, tracked. Never all-caps body.
5. **Serif × grotesque clash** — heavy opinionated display vs neutral workhorse (choose your own pairing).
6. **Gigantic numerals** — real figures as the primary graphic (tabular, tight).
7. **Outline / stroked / hollow** — `-webkit-text-stroke`, mix one hollow word in; keep AA contrast.
8. **One variable-axis move** — animate one axis (wght/wdth/opsz) once, then stop.
9. **Type-as-image / masking** — image/video clipped inside letters (`background-clip:text`; no gradient fills).
10. **Tight negative leading stacks** — display `line-height:0.85–0.95`; body stays 1.5–1.7.
11. **Mixed-size inline emphasis** — balloon/shrink a key word by scale (the bold replacement for the italic accent).
12. **One kinetic load gesture** — a single orchestrated entrance; content in markup, `prefers-reduced-motion` respected.

## Boldness vs. timidity
Restraint = precision in service of a bold idea, not safeness. A statement piece commits to:
**large scale** (dominates the viewport), **high contrast** (unambiguous size/weight/value jumps),
**a decisive single color or dramatic monochrome** (own one hue hard — not five soft, not a slop palette),
**confident asymmetry**, and **willingness to be loud**. Named failure: *timid / safe / tasteful-default*
(mid-size hero, medium-grey 600-weight type, everything centered, a card holding a fake stat).
Discriminators for bold-not-slop: is it **load-bearing** (removing it breaks the argument), **grounded**
(survives the swap test), **committed** (one idea fully, not three half-moves)?

## Forbid the median (run before building)
1. **Name the median** for this brief: its safe font, the split-hero+card layout, the italic-accent move, the fake-metric card.
2. **Refuse the whole cluster** — not one item; don't just swap indigo for cream+gold.
3. **Pick three different axes, grounded in the subject:** a different layout archetype, a different type move, a different font character (mine the subject, not the default lists).
4. **Verify divergence:** could this page belong to another brief unchanged? If yes, change an axis. Run the swap test on the standout.
5. **Non-repetition across builds:** keep archetype + type move + color commitment different from the previous build.

## Aesthetic direction & creative ambition (the gates are a FLOOR, not a ceiling)
The hard gates raise the floor; they are NOT a license to be timid. The opposite failure —
a safe page that passes every gate and bores — is also a fail. So before you build, commit
to a real creative direction and execute it fully:

- **Pick ONE extreme aesthetic tone and commit.** Choose a flavor — brutally minimal,
  maximalist, editorial/magazine, retro-futurist, art-deco/geometric, industrial/utilitarian,
  luxury/refined, organic/natural, soft/pastel, toy/playful — and design true to it.
  **Intentionality > intensity:** refined-minimal and loud-maximal both win; a half-committed
  middle loses. Name the **one unforgettable thing** someone remembers (usually your standout).
- **Match implementation complexity to the vision.** Maximalist → elaborate code, layered
  effects, orchestrated motion. Minimalist → restraint, precision, impeccable spacing/type/
  detail. Elegance is executing the chosen vision *fully*, not doing a little of everything.
- **Atmosphere & depth are craft levers** — texture, layered depth, decorative detail,
  considered shadow, a custom cursor — use them to avoid flat defaults. BUT execute them
  *within the gates*: depth from real material / grain / contrast / structure, never from
  dark+neon glow, an indigo→cyan gradient mesh, or glassmorphism.
- **Don't hold back.** Show what you can actually make when you commit to a distinctive
  point of view. The anti-slop rules tell you what to avoid; this tells you to still go big.
