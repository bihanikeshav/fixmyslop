# skills/

Agent skills shipped by this repo. Each folder is self-contained and installable; start
at its `SKILL.md`.

| Skill | What it does | Source of truth | Tests |
|---|---|---|---|
| `fixmyslop/` | UI design skill driven by the fixmyslop MCP tools: index + `design-law.md` + one file per pass + on-demand `reference/` | **Generated.** Edit `apps/engine/prompts.mjs` / `reference.mjs`, run `node scripts/build-skill.mjs`. `apps/engine/prompts.test.mjs` fails if the `.md` files drift | node:test |
| `fixmyslop-humanizer/` | Removes signs of AI writing from prose; fail-closed Python pipeline (`scripts/humanize.py` → anchors → pragmatics → rewrite → fidelity) | Hand-written. `structural_bridge.py` / `expendable_bridge.py` are repo-only evaluation tools that need `textslopbench/` | `tests/` (pytest) |
| `personality/` | Forces a bold, subject-grounded ideation process; no MCP dependency | Hand-written, except `reference/type-and-color.{md,json}` and the data block in `reference/slop-manifest.md`, generated by `scripts/build-personality-skill.mjs` | `tests/test_personality_type_and_color.py`, `packages/pipeline/src/personality-skill.test.ts` |

Borrowed rules are credited inline and in each `SKILL.md` frontmatter; see
`docs/DATA-AND-LICENSING.md`. The Worker serves `fixmyslop/` at `/skill` for one-line install
(`apps/INSTALL.md`).
