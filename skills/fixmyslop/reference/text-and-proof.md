# fixmyslop reference — Text & proof

_Craft knowledge to draw on, not a template. The gates in design-law.md are the only hard rules — invent for THIS subject and diverge freely._

Use this pass when an interface contains generated prose, technical claims, benchmarks, or a before/after writing tool. Keep control copy operational and outside broad prose rewrites. Preserve claim actors, polarity, modality, scope, temporal order, causal relationships, names, numbers, links, dates, and quotations; if bounded repair still fails, release the source unchanged.

Make the real mechanism visible: prefer a source → revision → audit workbench, annotated proof, or result ledger over a vague headline and generic feature cards. Show a clean control the system should leave alone and distinguish contextual signals from high-confidence edits.

Benchmark an identity/no-op baseline beside the system. Report useful intervention, clean-text preservation, claim safety, item counts, denominators, dataset/scorer versions, and uncertainty separately. Cluster uncertainty by the real sampling unit. A detector and its own rewriter can reward each other; never market that loop as human quality, and do not collapse trade-offs into an unregistered composite score.
