# AGENTS.md — start here

Orientation for any coding agent (or new human) opening this repo. Read this file, then
the README of the directory you are about to touch. `CLAUDE.md` points here.

## What this repo is

**fixmyslop**: a deterministic design engine that turns a product brief into distinct,
non-generic art directions plus gates that catch "AI slop" (overused fonts, colours,
layouts, prose). It ships as a Cloudflare Worker (REST + MCP), a static web workbench,
three agent skills, and two evaluation suites (UI and text).

Product contract: [`PRODUCT.md`](PRODUCT.md). Visual system: [`DESIGN.md`](DESIGN.md) /
`DESIGN.json`. Human overview: [`README.md`](README.md). All docs: [`docs/README.md`](docs/README.md).

## Commands

```bash
npm ci
npm test                 # vitest (packages) + node:test (apps) + ui-bench
npm run test:apps        # node --test apps/engine/*.test.mjs apps/worker/src/*.test.mjs
npm run test:packages    # vitest in packages/*
npm run typecheck
npm run build            # web build + tsc
npm run test:web         # smoke-check the web build
npm run benchmark:engine
python -m pytest -q      # 20 tests skip unless corpora are fetched
node scripts/check-repo-hygiene.mjs
```

CI (`.github/workflows/ci.yml`) runs all of the above. Keep it green.

## Rules that bite

1. **Test runners differ by folder.** `apps/*` and `benchmarks/*` use `node:test`.
   Running vitest there reports "0 tests" and exits 0 — a false green. `packages/*` use vitest.
2. **The engine is deterministic.** No `Math.random`, `Date.now`, fs or network in
   `apps/engine`. Randomness goes through the seeded `mulberry32`; RNG draw order in the
   perturb modules is append-only. Same input + seed must give byte-identical output.
3. **Generated files:** `skills/fixmyslop/**/*.md`, `skills/personality/reference/type-and-color.*`,
   `apps/web/build/`, `apps/web/viz/*.html`, `viz/font-projector.html`, `apps/engine/data/*.json`.
   Change the generator, not the output.
4. **The Worker is public and unauthenticated.** Anything reachable from `src/tools.mjs`
   takes attacker-controlled input: bound the work, cap sizes, never throw raw errors.
5. **Never commit** corpora, crawl output, screenshots/recordings, cookies or `.env`.
   Images are only allowed under `apps/web/` and `viz/personality-test/`
   (`scripts/check-repo-hygiene.mjs` enforces this). Put scratch captures in `.scratch/` (ignored).
6. **Fonts must be free for commercial use** (OFL, Apache-2.0, ITF FFL, CC0…). See
   `docs/DATA-AND-LICENSING.md`.
7. **Crawlers** must use the shared robots / URL-safety / user-agent helpers in
   `packages/crawl/src`. Third-party content is local research material only.
8. **Evidence over claims.** Benchmarks state sample sizes and limits. TextSlopBench's v2
   superiority verdicts are withdrawn pending a cluster-valid rerun — don't quote them.

## Keeping this index alive

Adding a top-level directory, a script, or a doc? Update the matching README and
`docs/README.md` in the same change. `scripts/check-repo-hygiene.mjs` fails CI when a
required index file is missing.

## Where to make a change

- New or changed gate/tool → `apps/engine/*.mjs` + test → expose in `apps/worker/src/tools.mjs` → if the skill text changes, edit `prompts.mjs`/`reference.mjs` and rebuild the skill.
- Font data/scoring → `packages/core` (maths) or `packages/pipeline` (ingest), then rebuild the index and `node scripts/build-service-bundle.mjs` / `build-font-runtime.mjs` to refresh `apps/engine/data`.
- Layout parsing → `packages/crawl/src/derive-layout-data.ts`; add a regression test for every heuristic you touch.
- Web UI → `apps/web/demo/app.jsx` + `app-styles.css`, following `DESIGN.md`.
- Humanizer behaviour → `skills/fixmyslop-humanizer/scripts/`, tests in `tests/`.
